Tài liệu ôn tập - Phần 2

Danh sách các file quản lý

  • dashboard.html: Giao diện HTML trang Dashboard.
  • js/dashboard.js: Cập nhật APIs, vẽ Chart.js, trích lọc dữ liệu CSV Our World in Data, và vẽ Canvas ánh xạ tọa độ nhiệt độ thế giới.
  • js/index.js: Cập nhật nồng độ CO2, IntersectionObserver, đếm số Easing và vẽ Canvas Sparkline trang chủ.

Giải thích cơ chế & Code chính

1. Gọi API bất đồng bộ song song
Dùng Promise.all([fetch1, fetch2]) cho phép gửi đồng thời cả hai yêu cầu HTTP. Tổng thời gian phản hồi bằng thời gian của API chạy lâu nhất, giảm tối đa thời gian chờ của client.
2. Đọc & Xử lý dữ liệu CSV lớn ở Client
Đọc chuỗi văn bản bằng fetch().text(), dùng split(/\r?\n/) chia dòng. Lọc dòng chứa "World" hoặc "OWID_WRL" từ năm 2018–2024. Nhân tổng điện (TWh) với tỷ lệ tái tạo để tính sản lượng xanh, trung bình cộng và chia cho 100 để tìm giá trị tương đương 1%.
3. Nội suy tọa độ địa lý lên Canvas
Bản đồ phẳng Mercator bị méo ở hai cực. Ta định nghĩa mảng các điểm mốc hiệu chỉnh vĩ độ/kinh độ thực tế (xPts, yPts) và dùng phương pháp nội suy tuyến tính từng đoạn (Piecewise Linear Interpolation) để ánh xạ chính xác vị trí thành phố lên ảnh nền Canvas.
4. Easing bộ đếm số chạy & Sparkline không mờ
- Bộ chạy số dùng requestAnimationFrame đồng bộ tần số quét màn hình giúp chuyển động mượt, tự động dừng khi ẩn tab. Easing cubic-out làm số chạy chậm dần khi về đích.
- Canvas Sparkline nhân kích thước vật lý với devicePixelRatio của màn hình Retina, sau đó dùng scale(dpr, dpr) để chống nhòe.

Câu hỏi phản biện từ Hội đồng

Hỏi: Em hãy giải thích từ khóa async và await?
Đáp: async khai báo một hàm bất đồng bộ trả về Promise. await dừng việc thực thi hàm cho đến khi Promise được giải quyết, giúp code bất đồng bộ nhìn giống đồng bộ tuần tự, dễ đọc hơn.
Hỏi: Làm thế nào đảm bảo trang không bị lỗi trắng màn hình nếu server API NASA/chất lượng không khí bị sập?
Đáp: Sử dụng khối lệnh try...catch. Nếu xảy ra lỗi mạng ở try, trình duyệt nhảy ngay vào catch và kích hoạt cơ chế Fallback lấy dữ liệu tĩnh trong hằng số FALLBACK_DATA để vẽ đồ thị, giữ trang hoạt động an toàn.
Hỏi: Làm thế nào để phát hiện thành phố gần nhất khi di chuột trên Canvas?
Đáp: Tính khoảng cách Euclid giữa chuột và từng thành phố: Math.hypot(mouseX - x_city, mouseY - y_city). Nếu khoảng cách nhỏ hơn 16 pixel, hiển thị Tooltip thông tin thủ đô.

Code mẫu thô viết tay

function drawTempPoint(canvas, lat, lon, temp) { const ctx = canvas.getContext('2d'); const x = ((lon + 180) / 360) * canvas.width; const y = ((90 - lat) / 180) * canvas.height; const grad = ctx.createRadialGradient(x, y, 0, x, y, 12); grad.addColorStop(0, temp > 25 ? 'rgba(239, 68, 68, 0.9)' : 'rgba(59, 130, 246, 0.9)'); grad.addColorStop(1, 'transparent'); ctx.fillStyle = grad; ctx.beginPath(); ctx.arc(x, y, 12, 0, Math.PI * 2); ctx.fill(); }
