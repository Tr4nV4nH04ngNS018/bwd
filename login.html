Tài liệu ôn tập - Phần 1

Danh sách các file quản lý

  • login.html, register.html, forgot-password.html: Giao diện HTML của các trang xác thực.
  • login.css: Định nghĩa hiệu ứng Glassmorphism & HUD.
  • app.js: Xử lý dropdown user & đồng bộ session đăng nhập.
  • auth.js: Động cơ lưu trữ danh sách tài khoản & kiểm tra đăng nhập/đăng ký/OTP quên mật khẩu.
  • js/universeBg.js: Bầu trời sao 3D & dải sao băng rơi làm nền.

Giải thích cơ chế & Code chính

1. Cơ chế Mock Authentication (localStorage)
Ứng dụng lưu mảng user vào localStorage bằng khóa mock_users_v1 dưới dạng chuỗi JSON thô (JSON.stringify). Khi đăng nhập, ta đọc ra (JSON.parse) và tìm kiếm email/mật khẩu khớp.
2. Bầu trời sao 3D (Three.js)
- Dùng Float32Array(particleCount * 3) để khởi tạo tọa độ (x, y, z) cho 2,000 hạt sao phẳng tốc độ cao.
- Lerp màu ngẫu nhiên giữa Xanh lá (0x4ade80) và Xanh dương (0x7dd3fc).
- Di chuyển camera theo chuột (Parallax) mượt mà bằng thuật toán Lerp: camera.position.x += (mouseX - camera.position.x) * 0.02.
3. Xoay đầu nhọn sao băng chéo trùng hướng rơi
Dùng Quaternion: quaternion.setFromAxisAngle(axis, radians), trong đó trục xoay là tích có hướng của vector hướng lên và vector vận tốc rơi, góc là góc giữa hai vector đó.

Câu hỏi phản biện từ Hội đồng

Hỏi: Hệ thống đăng nhập/đăng ký hoạt động thế nào khi không có database? Mất dữ liệu khi tải lại trang không?
Đáp: Tận dụng localStorage của trình duyệt để ghi trực tiếp xuống đĩa cứng thiết bị nên dữ liệu tài khoản được giữ nguyên vẹn kể cả khi tắt trình duyệt hay khởi động lại máy tính.
Hỏi: Quên mật khẩu hoạt động như thế nào?
Đáp: Mô phỏng sinh mã OTP 6 số cố định (123456) hiển thị trên giao diện/console, có cooldown đếm ngược 30 giây gửi lại. Khi nhập đúng, mật khẩu mới được cập nhật vào localStorage.

Code mẫu thô viết tay

function loginUser(email, password) { const users = JSON.parse(localStorage.getItem('mock_users_v1') || '[]'); const match = users.find(u => u.email === email && u.password === password); if (match) { localStorage.setItem('current_user', JSON.stringify(match)); alert('Đăng nhập thành công!'); } else { alert('Sai email hoặc mật khẩu!'); } }
